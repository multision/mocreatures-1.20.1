## Community fixes for Minecraft 1.20.1

- **Lollizaczek / Lollizak** — horse rear-leg animation fix in [PR #6](https://github.com/multision/mocreatures-1.20.1/pull/6), commit `4062f0077a1e96432b729122dbcb70d253c74c52`; zebra-shuffle animation and jukebox fixes in commits [`14150f5`](https://github.com/Dinocraft-cz/mocreatures-1.20.1/commit/14150f5), [`1c5ccf9`](https://github.com/Dinocraft-cz/mocreatures-1.20.1/commit/1c5ccf9), and [`2c29d3a`](https://github.com/Dinocraft-cz/mocreatures-1.20.1/commit/2c29d3a).
- **Dinocraft-cz / Vaniron** — integration and distribution of the zebra fixes in the [community fork](https://github.com/Dinocraft-cz/mocreatures-1.20.1/commits/main/), merge commit `3ba8f4096633b61c289dfa3b0772e79395957a8c`. The underlying code changes were authored by Lollizaczek / Lollizak.
- **ItsFadedMaybe / Faded** — [Elephant FIX](https://www.curseforge.com/minecraft/mc-mods/mo-creatures-elephant-fix), file `8507586`, published under GPLv3. Elephant animation signaling, rider positioning, kneeling duration, and access to storage while mounting were adapted into the main mod. The integration also prevents repeated kneeling resets and tells clients when mounting ends the kneeling animation.
- **Clickibait / ClickLarp and Pug** — [Mo' Creatures Nostalgia Edition - Fix](https://www.curseforge.com/minecraft/mc-mods/mo-creatures-nostalgia-edition-fix-legacy-model), including the legacy big-cat layer/mane fixes and later shark, bunny/dolphin persistence, and elephant fixes documented through version 1.0.5. Their investigation and community fixes informed the corresponding repairs here. These repairs were implemented in this repository's existing source; the All Rights Reserved add-on was not bundled or copied. Pug is credited by the project author as the principal contributor to the legacy-model work.

Contributor aliases above are taken from the linked project pages, Git history, and the server's public bug-report discussions. No co-author trailers are added to integration commits; imported commits retain their original authors.
